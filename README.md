# 📱 Google Sheets → WhatsApp Messaging Automation

An automated WhatsApp messaging workflow built using **n8n**, **Google Sheets**, and the **WhatsApp Cloud API**.

This project demonstrates how a Google Sheet can be used as a simple data source for managing contacts and messages, while n8n handles the automation, processing, and WhatsApp API integration.

---

## 🚀 Project Overview

The goal of this project is to automate WhatsApp messaging using data maintained in a Google Sheet.

Instead of manually copying phone numbers and messages and sending them individually, the workflow reads the required information from Google Sheets and automatically sends WhatsApp messages through the WhatsApp Cloud API.

# 📱 Google Sheets → WhatsApp Messaging Automation

---

## 🚀 Project Overview

The goal of this project is to automate WhatsApp messaging using data maintained in a Google Sheet.

Instead of manually copying phone numbers and messages and sending them individually, the workflow reads the required information from Google Sheets and automatically sends WhatsApp messages through the WhatsApp Cloud API.

## 🚀 Features

Read WhatsApp recipient information from Google Sheets.
Process multiple contacts using n8n.
Dynamically generate WhatsApp messages.
Send messages through WhatsApp Cloud API.
Use API authentication securely through n8n credentials.
Automate repetitive WhatsApp communication.
Build a reusable automation workflow.
Can be extended with status tracking and error handling.

📊 Google Sheet Structure

The Google Sheet acts as the data source for the workflow.

Example:

Name	Phone	Message	Status
Ram	+919XXXXXXXXX	Hello John!	Pending
Rams	+919XXXXXXXXX	Your order is confirmed.	Pending
John	+919XXXXXXXXX	Your appointment is confirmed.	Pending

The workflow can read each row and process the records automatically.

🔄 How the Automation Works
**Step 1 — Google Sheets**

The workflow reads the messaging information from Google Sheets.

The sheet contains information such as:

Name
Phone
Message
Status

**Step 2 — n8n Reads the Data**
n8n connects to Google Sheets and retrieves the required rows.

The workflow can then process each record individually.

Conceptually:
Google Sheets
      ↓
Get Rows
      ↓
Process Each Contact

**Step 3 — Prepare the WhatsApp Request**

The recipient phone number and message are dynamically mapped into the WhatsApp API request.

Example:
{
  "messaging_product": "whatsapp",
  "to": "919XXXXXXXXX",
  "type": "text",
  "text": {
    "body": "Hello! Your message was generated by n8n."
  }
}

**Step 4 — Send WhatsApp Message**

n8n uses the WhatsApp Cloud API to send the message.

The API request follows the structure:
n8n
 ↓
HTTP Request
 ↓
WhatsApp Cloud API
 ↓
Recipient

**Step 5 — Process the API Response**

After WhatsApp processes the request, the API returns a response containing information such as the WhatsApp message ID.

Example:
{
  "messages": [
    {
      "id": "wamid.HBgL..."
    }
  ]
}
This can be used for tracking and logging.

## 🔐 Authentication

The workflow uses credentials configured inside n8n.

For WhatsApp Cloud API, the workflow requires an appropriate Meta access token.

The token should never be stored directly inside the workflow JSON or committed to GitHub.

Recommended approach:
n8n Credentials
       ↓
Bearer Token
       ↓
WhatsApp Cloud API

Google Sheets authentication should also be configured through n8n's credential management.

## ⚙️ Setup
**1. Install n8n**

n8n can be installed locally or run using Docker.

Example Docker command:
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  docker.n8n.io/n8nio/n8n

Then open:
http://localhost:5678

**2. Configure Google Sheets**

Create a Google Sheet containing the required messaging information.

Example:
Name | Phone | Message | Status

Connect Google Sheets to n8n using the appropriate Google credentials.

**3. Configure WhatsApp Cloud API**
Create and configure a WhatsApp Business application through Meta.

You will need:
WhatsApp Business Account
Phone Number ID
Access Token
WhatsApp-enabled phone number

Configure the credentials inside n8n.

**4. Import the Workflow**

Import the workflow JSON into n8n.

After importing:
Configure Google Sheets credentials.
Select the required Google Sheet.
Configure WhatsApp credentials.
Verify the WhatsApp Phone Number ID.
Test the workflow with a single record.
Activate the workflow.
